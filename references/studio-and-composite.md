# 棚拍与合成

## 一、照着图去棚里拍

### 1. 机位高度和焦段跟图一样

图是贴地仰拍，你也要把相机放低；图是 85mm，你也用 85mm 左右。不然透视对不上，人放进去就是“贴上去的”。

现场做法：

- 把 MJ 图投到监视器或平板上，和实时画面并排；
- 先对机位高度（三脚架升到画面里地平线一致），再对焦段；
- 用同一画幅比例拍，不要后期再硬裁；
- 如果镜头有畸变，后期先做镜头校正，再合成。

### 2. 光照着人偶打

人偶哪边亮，你就在哪边放主光；人偶身上偏暖，就用暖光。

看三件事：

- **方向**：主光从画面左/右/顶来？
- **软硬**：阴影边缘是硬边还是渐变？
- **色温**：亮部偏暖还是偏冷？暗部有没有环境色？

### 3. 白棚适合柔光，硬光暗调要吸光

白棚的墙会把光反射得到处都是，柔光很容易做；但硬光、暗调的图（聚光灯、烛光）在白棚里暗部压不下去。

做法：在模特两侧立黑旗吸光，背景拉黑，主光加格栅或束光筒。不要指望后期把白棚压成黑夜，暗部会脏。

### 4. 悬浮、坐、躺的姿势要有东西撑着

用透明亚克力凳、白色方箱或苹果箱，后期抠掉。支撑物尽量在身体重心下方，别让模特用肌肉硬撑——硬撑的姿势看起来就是“在使劲”。

### 5. 和动物有接触的地方要垫出来

比如手搭在虎背上，就找个差不多高的东西让模特搭着，手的姿态才自然。接触点的高度、角度要和 MJ 图一致，后期才能补毛发压痕和投影。

### 6. 有镜子的画面要多拍几张

镜子里的倒影也得换成真人，所以要多拍一张背面、一张侧面，后期贴进镜片里。拍的时候注意：

- 镜面要干净，不要有摄影师和灯架的倒影；
- 倒影的视角和真人镜头要能对上；
- 多拍几张不同角度的备用。

### 7. 现场清单

- [ ] 机位高度、焦段、画幅与 MJ 图一致
- [ ] 主光方向、软硬、色温与人偶一致
- [ ] 暗调图有黑旗/束光，不靠后期压暗
- [ ] 悬浮/坐/躺有支撑物
- [ ] 接触点有同高垫物
- [ ] 镜面画面补拍背面、侧面
- [ ] 拍一张空棚参考（没有人的干净背景），方便后期对色
- [ ] 备份卡、检查焦点和快门速度

## 二、擦人偶，换真人合成

### 1. 在 MJ 编辑器里擦掉人偶

擦除区的提示词**只写这里应该是什么，绝对不写“人”**。写了 `person`、`girl`，反而会把人招回来。

例如：

- 地面：`wet stone flagstones, continuous paving, soft reflections`
- 墙面：`white plaster wall with black tile trim, slight weathering`
- 虎背：`white tiger fur, orange and black stripes continuing naturally`

不要写 `remove the girl`、`no person here`。

### 2. 影子和倒影一起擦

地上的投影、水面的倒影最容易留下前一个人偶的痕迹。擦除范围要比人偶本身大一圈，把影子和倒影包进去。

### 3. 接触点要补细节

人和老虎挨着的地方，要把毛发的压痕、投影重新画上，不然人像是浮在老虎身上。注意：

- 接触处的毛发要有被压弯的方向；
- 接触点下方要有接触阴影（ambient occlusion）；
- 人和动物之间不要有“空气缝”。

### 4. 调色往背景靠

背景是 CG 质感的话，人片的饱和度、通透感、皮肤质感也要往那边调一点。

具体做法：

- 先对黑场和白场，再对中间调；
- 用曲线分别调 RGB，不要只拉整体饱和度；
- 加一点点背景的噪点和颗粒，盖住人片的“干净感”；
- 景深要匹配：背景虚焦，人也要有对应的边缘柔化；
- 高光色温向背景高光靠，暗部色温向背景暗部靠。

### 5. 自动化擦除（脚本 `erase`）

`scripts/mj_autopost.py erase` 走 V8.2 垫图编辑（reference edit），适合：

- 人偶轮廓清楚、背景纹理连续、没有复杂遮挡；
- 只需要一张干净背景板，不要求逐像素还原。

不适合：

- 手部交叠、镜面倒影、人偶大面积遮挡主体；
- 需要保留原图每一个细节的场景。

reference edit 会整图重绘，可能改变构图、纹理或光线。**一次出 4 张，逐张目检**；不干净就转 MJ 网页 Editor 的遮罩擦除或 Photoshop 生成式填充。不要因为脚本返回 `SUCCESS` 就认为擦干净了。

### 6. 合成验收清单

**几何**

- [ ] 机位高度一致（地平线、消失点对得上）
- [ ] 焦段/透视一致（近大远小比例对得上）
- [ ] 人物脚底/接触点落在正确位置
- [ ] 人物比例与场景中的参照物一致

**光影**

- [ ] 主光方向一致
- [ ] 阴影方向、长度、软硬一致
- [ ] 接触点有接触阴影
- [ ] 高光位置和形状合理
- [ ] 色温（亮部/暗部）一致

**边缘与质感**

- [ ] 头发、手指、衣物边缘没有白边/灰边
- [ ] 人偶没有残留（残肢、灰影、重复物件）
- [ ] 皮肤质感与背景的 CG/实拍质感统一
- [ ] 噪点、颗粒、景深匹配
- [ ] 镜面倒影已替换且视角正确

**叙事**

- [ ] 人物视线与动物/道具的关系成立
- [ ] 动作能接上上一张/下一张
- [ ] 没有“为了合成而合成”的多余人偶痕迹

## 三、交付前最后三句话

1. **人偶是尺子、是分镜、也是灯光图**，别把它当成多余的东西。
2. **一次只改一个地方**。景别、焦段、颜色一起改，就不知道是哪一处起了作用。
3. **MJ 不听话的时候，先想想它是怎么“误会”你的**，找到原因再改，比反复重刷快得多。
