# 排故事线与补镜头

刷出一堆好图之后，单张都好看，但放在一起是散的。这一步把它们串成一个故事。

## 1. 先按“场景 + 光线”分组

比如白虎那组 22 张，可以分成：雨巷、正午庭院、漏窗、苔园、雪地、石桥、乌篷船。

分组不是为了归档，而是为了看清**哪些图能放在同一场戏里**。同一场景、同一光线的图，服装、情绪、动作可以连贯；跨组的图需要转场。

## 2. 按光线把组排成时间顺序

雨天上午 → 雨停正午 → 午后 → 黄昏 → 夜里。

光线就是时间轴，顺着排最自然。不要按“哪张好看”排，观众会感觉时间在跳。

## 3. 对不上的组，给它找个理由

夏天的故事里混进了雪景，就让雪景变成“午睡时做的梦”。

常见理由：

- 梦境 / 回忆 / 想象
- 时间跳跃（字卡或一个空镜带过）
- 地点切换（车、船、门、走廊）
- 情绪外化（雪 = 孤独，雨 = 压抑）

理由不需要复杂，但必须让观众一次看懂。看不懂的转场不如删掉。

## 4. 在两组之间补一张过渡镜头

常用的五种：

| 类型 | 作用 | 例子 |
|---|---|---|
| 开场 | 第一次相遇，远远对视 | 长焦远景，人和虎在巷子两端 |
| 动作衔接 | 接上一组的动作收尾 | 雨停了收伞、老虎抖毛 |
| 换场景 | 交代移动 | 背影穿过一道门 |
| 转场特写 | 从现实切到梦里 | 只拍一只手 + 一片雪花 |
| 结尾 | 收束 | 超长焦远景，人和动物变成小剪影走远 |

补镜头时，先想“上一组最后发生了什么、下一组第一帧需要什么”，再决定补哪一种。不要为了好看硬塞一个空镜。

## 5. 补镜头时写清楚“两者之间的关联”

人和动物不能各干各的。可以用这几种方式连起来：

- **手**：指尖快碰到鼻子，但还没碰到（`fingertips almost touching`）
- **视线**：两个互相看着（`the two looking at each other`）
- **道具或特效**：伞甩出的水珠和老虎抖出的水珠在两者之间撞到一起
- **同一动作**：人转头，老虎也转头；人停，老虎也停
- **同一光源**：光从同一侧来，影子朝同一方向倒

关联要写在 prompt 里，不能指望后期“看起来像”。MJ 不会自动让两个主体产生关系。

## 6. 输出一张镜头表

排完故事线，输出 `shots.json` 或一张表，至少包含：

| 字段 | 说明 |
|---|---|
| `id` | 镜头编号，建议 `01-rain-alley` 这种可读格式 |
| `group` | 场景 + 光线分组 |
| `time` | 故事内时间（上午/正午/黄昏/夜） |
| `framing` | 景别 |
| `focal` | 焦段 |
| `subject` | 人偶 + 动物/道具 |
| `interaction` | 两者的关系 |
| `scene` | 环境 |
| `light` | 光线 |
| `status` | 待出图 / 已出图 / 已擦除 / 已合成 / 重跑 |

镜头表是后面棚拍和合成的施工图。没有镜头表就开始拍，现场一定乱。

## 7. 检查故事线是否成立

- 不看 prompt，只看缩略图，能说出“这是同一个故事”吗？
- 时间顺序有跳变吗？跳变有理由吗？
- 每个场景至少有一张“关系镜头”（人和动物/道具同框且有关联）吗？
- 开场和结尾是同一套视觉语言吗（焦段、色调、构图）？
- 有没有两张图长得几乎一样、可以删掉的？
